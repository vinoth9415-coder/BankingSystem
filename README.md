# Online Banking System

A modern, full-stack Banking Application with a React frontend and Spring Boot backend.

## 🚀 Features
- **User Authentication**: Secure Login & Registration with JWT.
- **Account Management**: View balances, create accounts, and view transaction history.
- **Transfers & Transactions**: Instant fund transfers and real-time transaction statements.
- **Responsive Modern UI**: Built with React 19, Tailwind CSS v4, and Lucide/React Icons.
- **Export Reports**: Generate statements in PDF and Excel formats.

## 🛠️ Tech Stack
- **Frontend**: React 19, Vite, Tailwind CSS, Axios, Chart.js
- **Backend**: Java Spring Boot, Spring Security, JPA/Hibernate, MySQL

## 📦 Deployment
- **Frontend**: Deployed on Vercel (`https://banking-system-vinoth8.vercel.app`)
- **Backend**: Spring Boot API
